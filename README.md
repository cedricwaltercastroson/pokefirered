# Pokémon FireRed

This is a disassembly of Pokémon FireRed.

To set up the repository, see [INSTALL.md](https://github.com/cedricwaltercastroson/pokefirered/blob/main/INSTALL.md).

## Features

- Sevii Islands removed. Sticking to the original classic feel.
- Moltres can be found at Victory Road, similar to the original Pokémon games.
- Added a level 5 roaming Mew after becoming the Pokémon League Champion. (Mew has a legal byte set so it obeys.)
- Move Deleter, Move Tutor, and Starter Ultimate Move Tutor are located in the same house in Fuchsia City. All services are free.
- Disabled trading and battling on the 2F of Pokémon Centers.
- Added the ability to refill move PP after battles.
- Safari Zone Pokémon are captured in standard Poké Balls.
- All 151 original Pokémon can be caught in a single ROM.
- EXP Share is enabled by default without requiring an item. (The aide who gives the item has been removed.)
- Faster saving with unnecessary confirmation prompts removed.
- All Pokémon are genderless, similar to Generation 1.

## Following Pokémon

- Added Pokémon following the player throughout the overworld.
- Following Pokémon support their respective sprites and shiny colours.
- Added interactions with following Pokémon.
- Improved follower movement, positioning, and natural door entry.
- Following Pokémon support map transitions, warps, and special movement events.
- Added follower compatibility with Surf, Fly, and other field actions.
- Added follower handling for Pokémon Centers, the Pokémon League, and Hall of Fame.
- Improved follower restoration after saving, loading, and Quest Log events.

## Day and Night System

- Added a Crystal-inspired day and night system.
- Day and night alternate every 30 minutes.
- Added darker nighttime overworld colours.
- Added nighttime palettes for wild and trainer battles.
- Original daytime battle colours are preserved.
- Added faster, smoother day and night transitions.
- Added day and night compatibility with Safari Zone maps.
- Added a sleep system in the player's bedroom in Pallet Town.
- Added dynamic weather effects, including rain and thunderstorms.
